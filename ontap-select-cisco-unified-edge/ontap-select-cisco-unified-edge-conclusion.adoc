= Conclusão
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
A implementação do FlexPod Edge com storage definido por software oferece aos clientes um caminho prático para serviços de dados corporativos na borda. A arquitetura combina a plataforma Unified Edge compacta e gerenciada centralmente da Cisco com os serviços de dados consolidados do ONTAP, permitindo storage definido por software em um único chassi que pode suportar cargas de trabalho locais onde os dados são criados e manipulados.
